# Airport Management System - Database Design & Implementation

## 📌 Project Overview
A relational database system designed to manage and organize airport operations, flight schedules, and passenger data. This project covers the full lifecycle of database development from conceptual modeling to SQL querying.

---

## 🛠️ Key Components
* **Conceptual & Logical Design:** 
  * Entity Relationship Diagram (**ERD**) modeling entities, relationships, and constraints.
  * Relational Schema mapping with Primary and Foreign Keys.
* **Database Implementation:**
  * Structured SQL script (`TASK3QUE.sql`) for creating tables, defining constraints, and populating data.
* **SQL Queries:**
  * Complex analytical queries utilizing `JOIN`s, aggregations, and data filtering to answer operational business questions.

---
